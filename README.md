# Ronojoy Das — Software Development Engineer Portfolio

A responsive personal portfolio aligned with the current one-page CV.

## Run locally
Open `index.html` in Chrome or Edge, or use VS Code Live Server.

## Deployment
Upload the complete `ronojoy-portfolio` folder to GitHub Pages, Cloudflare Pages, Netlify or another static host. Keep the `assets` folder alongside `index.html`.
